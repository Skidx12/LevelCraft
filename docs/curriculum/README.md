# LevelCraft Curriculum Governance

This directory contains the planning and quality controls for LevelCraft's Java 17 and Spring Boot learning system.

## Current artifacts

- [`PHASE-0-CURRICULUM-AUDIT.md`](./PHASE-0-CURRICULUM-AUDIT.md) — authoritative curriculum inventory, dependency order, current-to-target mission mapping and Java 17 boundary.
- [`CONTENT-REVIEW-SCORECARD.md`](./CONTENT-REVIEW-SCORECARD.md) — mandatory review rubric for every mission before publication.
- [`PHASE-1-ROLLOUT.md`](./PHASE-1-ROLLOUT.md) — versioned content platform, validation, golden mission migration and compatibility record.

## Governance rule

Learner-facing content remains in `app/content`. Planning, editorial controls and audit records live here. No mission should be promoted from Content Review Mode until it passes the scorecard and all blocking checks.
