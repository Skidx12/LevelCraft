# LevelCraft Mission Content Review Scorecard

## Purpose

Use this scorecard before a mission leaves Content Review Mode. It measures technical correctness, beginner readiness, instructional progression and product usability.

The total score is 100. A mission requires:

- no blocking failure;
- at least 85/100 overall;
- at least 70% within every scored category;
- explicit Technical, Beginner and Editorial approval.

## Blocking failures

Any checked item below prevents publication regardless of score.

- [ ] The mission assesses an untaught prerequisite.
- [ ] Starter code is incomplete or does not compile on the declared version.
- [ ] Expected output does not match actual behaviour.
- [ ] Instructions reference a missing class, file, package, service or database.
- [ ] The learner is not told where to perform the work.
- [ ] Acceptance criteria cannot be objectively verified.
- [ ] The mission teaches an unsafe pattern as the recommended production solution.
- [ ] Content or artwork lacks acceptable ownership or licensing.
- [ ] A Java exercise requires a feature newer than Java 17.
- [ ] A required step depends on an undeclared external service or paid API.
